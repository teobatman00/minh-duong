## Overview

This is a Docusaurus 3.0 personal website/blog (Vietnamese language) covering finance and technology topics, deployed to GitHub Pages at `teobatman00.github.io/minh-duong`.

## Commands

Package manager is **yarn** (see `yarn.lock`; `README.md` uses yarn commands).

- `yarn start` — run local dev server with live reload
- `yarn build` — production build into `build/`
- `yarn typecheck` — run `tsc` (no emit, type-checking only)
- `yarn clear` — clear Docusaurus cache (`.docusaurus/`), useful when content/config changes don't seem to take effect
- `yarn serve` — serve the production build locally
- `yarn swizzle` — eject/override a theme component (used to create files under `src/theme/`)
- `yarn deploy` — build and push to `gh-pages` branch (`GIT_USER=<github-username> yarn deploy`, or `USE_SSH=true yarn deploy`)

There is no test suite or linter configured beyond `tsc`.

## Configuration & environment

- All site config lives in `docusaurus.config.ts`. Environment-driven values (site URL/baseUrl, Firebase, Giscus, Algolia, GitHub API) are loaded from `.env` via `docusaurus-plugin-dotenv` (`process.env.*`).
- `.env` is committed (these are public/client-side keys for Firebase, Algolia, Giscus). When adding new env-driven config, follow the existing `APP_*` / `FIREBASE_*` / `GISCUS_*` / `ALGOLIA_*` naming.

## Content structure

- `docs/` — documentation/tutorial content. Sidebar (`sidebars.ts`) is auto-generated from the filesystem (`type: 'autogenerated', dirName: '.'`). Each topic folder can have a `_category_.json`. Content can be `.md` or `.mdx`.
- `blog/` — blog posts, one folder per post (`index.mdx` + assets), plus `authors.yml`. Routed via the custom blog plugin below (routeBasePath `blog`).
- Both docs and blog support KaTeX math (`remark-math` + `rehype-katex`, loaded via the configured KaTeX stylesheet).

## Custom plugins (`plugins/`)

- **`custom-blog.ts`** — wraps `@docusaurus/plugin-content-blog`. After the default blog plugin loads content, it additionally registers the **home page route** (`/`) with component `@site/src/components/Home/index.tsx`, passing it `homePageBlogMetadata` (blog title/description/post counts) and `recentPosts` (the 5 most recent posts, each with metadata + a truncated MDX `Preview` component). Any change to the homepage's "recent posts" behavior goes through this plugin, not through `src/pages`.
- **`image-zoom/`** — registers a client module (`zoom.ts`) that adds image zoom-on-click behavior site-wide via `getClientModules()`.

## Theme overrides (`src/theme/`)

Swizzled/overridden Docusaurus theme components — these intercept the default rendering and should be kept in sync with upstream Docusaurus theme APIs (`@theme-original/...`, `@docusaurus/theme-common/internal`):

- `BlogPostItem/*` — heavily customized (Header/Title/Authors/Info, Footer, Container, Content). The `Footer` injects `BlogReactions` (see below) and tag/read-more rendering.
- `DocItem/Layout` — custom doc page layout/styles.
- `MDXComponents` — extends the default MDX component map with `Icon` (FontAwesome `FontAwesomeIcon`), usable as `<Icon ... />` inside any `.mdx` file.
- `Tag`, `TagsListInline`, `BlogListPage` — custom tag rendering/list page.

## Blog reactions (Firebase)

- `integration/firebase.js` initializes Firebase (config from `.env` `FIREBASE_*` vars) and exports `firestore`.
- `integration/reactions.js` reads/writes per-post reaction counts in the Firestore `reactions` collection (keyed by post slug) and mirrors per-user reaction state in `localStorage`.
- `customizations/BlogReactions.jsx` (rendered from `src/theme/BlogPostItem/Footer`) renders one `components/ButtonReaction` per reaction defined in a post's frontmatter `reactions` field, wrapped in `<BrowserOnly>` since Firestore is client-only.

## Portfolio page (GitHub API)

- `src/pages/portfolio.tsx` fetches the user's GitHub repos client-side via `src/lib/client/GithubRepositoriesClient.ts` (axios call to `${API_GITHUB_URL}/users/${GITHUB_USERNAME}/repos`), typed by `src/lib/dto/ListRepositoriesUserResponse.ts`. Per-language colors come from `static/file/languages_colors.json`.

## Styling

- TailwindCSS is scoped with the `tw-` prefix and `preflight` disabled (so it doesn't conflict with Docusaurus/Infima base styles). Dark mode follows Docusaurus's `data-theme="dark"` class.
- Tailwind content globs cover `src/**/*.{js,jsx,ts,tsx}`, `docs/**/*.mdx`, and `blog/**/*.mdx`.
- Global CSS overrides live in `src/css/custom.css`.

## Shared UI components

- `src/components/shared/` — reusable building blocks (`Card`, `Modal`, `ImageGallery`) used across pages like `Home`, `portfolio.tsx`, `about-me.tsx`, and `img-gallery`.

## Deployment

`.github/workflows/deploy.yml` builds with `yarn build` and deploys `build/` to the `gh-pages` branch via `peaceiris/actions-gh-pages` on every push to `main`.
